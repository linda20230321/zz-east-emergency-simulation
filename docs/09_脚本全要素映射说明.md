# 应急演练脚本全要素映射说明

基线版本：0.7.0

## 1. 映射口径

系统以《因水害影响北京方向列车大面积晚点旅客滞留疏散应急演练脚本4.23》为唯一业务时序依据。`lib/scenario-script.ts` 保存“时间—地点—流程—岗位—人员—设备—操作—展示内容”关系，`lib/simulation.ts` 将其转换为实时设备状态，界面同步显示底图点位、设备气泡、人员流向和当前追溯记录。

地图采用“同类、同位置设备聚合为一个点位，实物数量单独统计”的方式。当前为43个设备组、456件设备与应急物资，另有6个监控点，总计462个物理资产。脚本未给出数量的社会联动人员或外部系统不虚构数量，仅在职责流程中呈现。

## 5. 可验证方式

1. 点击左侧15个节点，核对当前流程、地点、岗位职责和设备操作；
2. 点击底图设备，核对名称、安装位置、数量、责任人、状态及脚本节点；
3. 广播或导向屏产生消息时核对气泡原文；点击正文手动朗读，点击“×”关闭，随后点击设备图标可重新打开；
4. 打开监控总窗，核对六路画面与底图摄像机点位及脚本场景；
5. 在09:35—09:46连续播放，核对G806、G1808、G51三轮放行以及区域人数、路线和设备状态同步变化；
6. 核对3F、2F、1F固定人数标牌与区域汇总一致，并在三轮放行阶段核对车次、站台和乘车人数卡片。
7. 执行 `npm test`，验证事件、设备数量、监控映射、路径、交互结构、数据库和生产构建。

## 6. 数据边界

设备点位为总体布局图上的归一化参考坐标，不具备测绘精度。人员数量在脚本锚点之间采用守恒插值，真实论文或验收实验须使用视频计数、人工统计或脱敏客流序列校准。脚本未提供的设备实测数量、接口协议和媒体流不得以演示数据替代正式证据。
