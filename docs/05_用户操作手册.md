# 用户操作手册

基线版本：0.8.0

## 1. 界面构成

- 顶部动态看板：全站客流、10分钟站内积压预判、站内实时积压、西广场承接、晚点列车、停运列车、激活设备和仿真时刻；
- 左侧事件链：15个关键节点，点击可直接跳转；
- 中央站区：以北向上的高清深色总体布局图为连续底图，同屏展示3F候车层、2F站台层和1F出站层，清晰标注四向出口，并在固定位置显示各层实时总人数；
- 路线推荐：同时列出候车室至西广场的四条候选路线、距离、预计时间、密度和综合代价，青色高亮为实时推荐；
- 右侧态势：当前事件、精简设备联动数量和数据口径；
- 流程追溯：当前节点处置流程、岗位职责、设备操作、执行人及原文内容；
- 底部控制：播放/暂停、重置、拖动时间轴和0.5—10倍速。

## 2. 基本操作

1. 点击播放按钮开始推演；当前版本为压缩演示时间，不代表真实分钟速度；
2. 点击左侧任一事件直接跳转到对应时刻；
3. 拖动底部滑块查看任意时刻的区域人数和设备状态；
4. 沿连续底图纵向查看三层态势，无需切换楼层；
5. 点击站区内的设备图标查看设备ID、安装位置、实物数量、当前状态、责任岗位和脚本节点；
6. 在总图空白区域按住鼠标左键拖拽，可在无滚动条视口中平移底图；右上角按钮用于放大、缩小和复位；
7. 按住监控窗标题栏可拖动窗口，点击标题栏右侧按钮可折叠单窗；“收起监控/展开监控”控制整组画面；
8. 在09:21—09:35观察四条候选路线；客流密度变化后，推荐卡和底图高亮路线会自动切换，监控窗同步显示最新推荐；
9. 广播或导向屏气泡出现后，点击气泡正文可由浏览器语音朗读，点击右上角“×”关闭；关闭后点击对应设备图标可再次打开；
10. 09:35—09:46继续播放可依次查看基础候车、G806、G1808和G51四个内部阶段；
11. 当对应车次开始检票下站台时，2F位置出现站台乘车卡片，可查看车次、站台和实时乘车人数；
12. 点击重置返回09:00。

## 4. 读图规则

旅客点在全局视图中每点约代表50人。绿色、黄色、橙色、红色依次表示低、中、高和超高密度。设备绿色/青色表示开放或激活，黄色表示限行/警示，红色表示紧急播报或应急显示，灰色表示关闭。罗盘固定为上北、下南、左西、右东；四条动态路线均可见，推荐路线加粗发光。

绿色、黄色、橙色、红色人员圆点分别对应`d<0.30`、`0.30≤d<0.60`、`0.60≤d<0.85`、`d≥0.85`。Web主图不再显示KDE网格、深色椭圆、区域多边形、密度数值/等级标签和图例；人员圆点始终限制在所属区域显示范围内。

数字看板中，红色表示积压或停运风险，黄色表示关注，绿色表示预测值下降。`▲/▼`及变化量反映前1分钟变化；预判卡显示当前仿真模型推演的10分钟后站内积压人数。趋势线随时间轴每0.25分钟刷新，数值变化时会短暂高亮。

09:21—09:35显示向西广场疏散，改进型A*根据曼哈顿距离、路线长度和实时密度重算推荐；09:35后进入分批回流阶段。若人数与脚本锚点之间处于中间时刻，界面显示的是工程插值结果。

## 5. 已知限制

底图依据所提供总体布局信息图完成深色高清重绘，图内标题、连线说明和底部图标说明区已移除；设备、路线、人员显示范围与监控为归一化参考坐标，不具备测绘精度；悬浮窗使用与主图相同的仿真Agent快照，尚未接入真实监控视频。
