# 用户操作手册

基线版本：0.3.0

## 1. 界面构成

- 顶部指标：仿真总人数、候车厅人数、西广场人数、激活设备、视频监控和仿真时刻；
- 左侧事件链：15个关键节点，点击可直接跳转；
- 中央站区：以总体布局图为连续底图，同屏展示3F候车层、2F站台层和1F出站层；
- 右侧态势：当前事件、系统动作、五类设备联动比例和数据口径；
- 底部控制：播放/暂停、重置、拖动时间轴和0.5—10倍速。

## 2. 基本操作

1. 点击播放按钮开始推演；当前版本为压缩演示时间，不代表真实分钟速度；
2. 点击左侧任一事件直接跳转到对应时刻；
3. 拖动底部滑块查看任意时刻的区域人数和设备状态；
4. 沿连续底图纵向查看三层态势，无需切换楼层；
5. 点击站区内的设备图标查看设备ID、状态、联动依据和审计时刻；
6. 在总图空白区域按住鼠标左键拖拽，可在无滚动条视口中平移底图；右上角按钮用于放大、缩小和复位；
7. 按住监控窗标题栏可拖动窗口，点击标题栏右侧按钮可折叠单窗；“收起监控/展开监控”控制整组画面；
8. 点击重置返回09:00。

## 3. 快捷键

| 快捷键 | 操作 |
|---|---|
| 空格 | 播放/暂停 |
| R | 重置到09:00 |
| 左方向键 | 后退1分钟 |
| 右方向键 | 前进1分钟 |

## 4. 读图规则

旅客点在全局视图中每点约代表50人。绿色、黄色、橙色、红色依次表示低、中、高和超高密度。设备绿色/青色表示开放或激活，黄色表示限行/警示，红色表示紧急播报或应急显示，灰色表示关闭。动态虚线及箭头表示当前激活路线及方向。

09:21—09:35显示向西广场疏散；09:35后切换为从西广场向3F回流。若人数与脚本锚点之间处于中间时刻，界面显示的是工程插值结果。

## 5. 已知限制

底图来自所提供总体布局信息图，界面仅隐藏连线说明文字和底部图标说明区，原始文件未改写；设备、路线与监控为归一化参考坐标，不具备测绘精度；悬浮窗为仿真画面，尚未接入真实监控视频和语音。
