# 实验研究与论文专利数据计划

基线版本：0.3.0

## 1. 当前阶段原则

现在只建立“将来能够产生可信理论成果”的数据结构与实验规范，不预先杜撰创新点、效果数字、论文结论或专利权利要求。理论贡献必须在系统稳定、参数可校准、实验可重复后从数据中提炼。

## 2. 候选研究问题

1. 多层枢纽在设备受限条件下，时变路径与动态指示协同是否降低峰值密度和疏散时间；
2. “站内—西广场—回流”双向切换中，何种触发阈值能兼顾安全和乘车效率；
3. 视频—数字孪生在总量、密度和路径三一致约束下，如何建立可验证的校准方法；
4. 多部门应急策略作为规则组合时，如何度量设备联动的边际贡献和冲突成本。

## 3. 实验设计

采用基线方案、单因素消融和多策略组合：固定客流与随机种子，分别关闭动态指示、绿色通道、动态重路由、分区候车或高普联动；再对密度阈值、开放时刻、通道能力和旅客服从率进行多水平实验。每组至少使用多个随机种子，报告均值、标准差、置信区间和效应量。

## 4. 必采数据

- 每分钟区域人数、密度、流入、流出、速度和队列；
- 每个设备状态变化与触发来源；
- 每条路径使用人数、切换次数和旅行时间；
- 关键事件延迟；
- 总量守恒、路径合法性和状态机检查结果；
- 运行环境、引擎/配置版本、随机种子和参数；
- 视频/人工观测的真实值与标注质量。

## 5. 论文成果门槛

只有当模型在独立观测集上达到预先设定的误差阈值，并且关键策略相对基线具有统计显著且具有实际意义的改进时，才提炼理论命题。论文至少应包含：问题定义、三一致校准框架、事件驱动数字孪生模型、实验设计、误差与敏感性分析、消融实验和适用边界。

## 6. 专利文本准备门槛

专利应围绕真实可实施的技术方案，而非业务规则堆叠。候选方向包括：基于视频观测约束的多层枢纽人群数字孪生状态同步方法；面向疏散—回流切换的设备—路径—指示协同控制方法。正式申请前需完成现有技术检索、区别特征确认、实施例数据、流程图、系统框图和可复现算法步骤，再撰写权利要求书。

## 7. 防止成果失真

演示插值数据、占位坐标和未校准参数不得进入正式效果结论。论文表格必须能追溯到运行批次与原始数据；专利实施例不得宣称尚未实现或无法验证的功能。
